# `.code-forge.yml` configuration reference

Generated by `node scripts/gen-config-doc.mjs` from `schema/code-forge.schema.json` — do not hand-edit this file. Run `node scripts/gen-config-doc.mjs --check` in CI to catch a schema change that was not followed by a regeneration.

Plan v1.2 §1.3 — every key any section of the plan reads must appear here. additionalProperties: false everywhere a key set is fixed; a typed additionalProperties schema (never bare true) marks the handful of genuinely open-ended maps (thresholds.<question>, system1.criteria_extra, known_extra, keys, review.second_levels — the last restricted to L0..L3 keys only via propertyNames). v1.3 (B1.1) amendment: review.max_rounds_per_file/recheck_scope/late_findings (§4.11), budget.block_cases (§10.7), caps.coders re-defaulted to 2 (R10), tmp.root (§9.6/§1.2, V12).

`version`, `provider` and `levels` are required. `version`, `provider` and `levels` have no schema-level default; a config omitting any of them is refused.

Every other key defaults as shown, or is entirely absent from a minimal file. `additionalProperties: false` applies everywhere a key set is fixed; the rows marked `<key>` are the handful of open-ended maps where the schema accepts a caller-chosen name (a question id, a level name, a key name, a provider id).
